# PAN-based KYB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate tenant onboarding on a synchronous, OTP-free PAN existence check (mock-first), replacing the abandoned GST-OTP design; the free-email-domain block and company-email login move to Auth0 config (no app code).

**Architecture:** `POST /onboarding` verifies the submitted PAN **before** creating anything (verify-then-create): on success it creates the tenant already KYB-`VERIFIED` and enqueues the pipeline; on failure it returns 422 and creates nothing. PAN verification lives in a thin `clients/pan_client.py` (mock path default-on so it runs with no credentials), wrapped by a `modules/tenant_onboarding/kyb.py` surface that the API calls. The Auth0 email gate and passwordless login are documented as ops steps.

**Tech Stack:** Python 3.13 · FastAPI · SQLAlchemy 2.0 async (asyncpg) · Alembic · ARQ · pydantic v2 / pydantic-settings · httpx · pytest (`asyncio_mode = auto`).

## Global Constraints

- **Environment:** the host has no local Python 3.13/uv; run **every** command inside the app container, e.g. `docker compose exec app uv run pytest …`. Postgres and Redis are up in the compose stack, so integration tests work there.
- **Branch:** all work lands on `feature/pan-kyb` (already created off `00252d3`). Never push to `main`.
- **TDD:** failing test first → watch it fail for the right reason → minimal code → green → commit. Commit after every task.
- **mypy strict over the whole repo** (`uv run mypy .`), including `tests/`. A `TypedDict` is **not** assignable to `dict[str, Any]` — convert with `dict(...)` when persisting.
- **ruff** line length 100 (`uv run ruff check .`, `uv run ruff format .`).
- **`kyb_status` is a bare `String` column** (mirrors `onboarding_status`), so the DB returns a plain `str`. Compare with `==`, never `is` (`KybStatus.VERIFIED == "VERIFIED"` is `True`; `is` is `False`).
- **Dependency rule:** `api → modules → shared → clients → core`. The API calls `modules/tenant_onboarding/kyb.py`, which calls `clients/pan_client.py` — the API does **not** import `clients/` directly.
- **Commit message prefixes:** `feat:`, `fix:`, `test:`, `docs:`, `refactor:`. End commit messages with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

class KybStatus(StrEnum):
    """KYB verification state for a tenant. PAN flow only ever persists VERIFIED;
    PENDING is the column default and FAILED is reserved for future admin use."""

    PENDING  = "PENDING"
    VERIFIED = "VERIFIED"
    FAILED   = "FAILED"


PAN_PATTERN = re.compile(r"^[A-Z]{5}[0-9]{4}[A-Z]$")


def normalize_pan(value: str) -> str:
    """Strip, uppercase, and validate an Indian PAN. Raise ValueError if malformed."""
    candidate = value.strip().upper()
    if not PAN_PATTERN.match(candidate):
        raise ValueError("pan must match ^[A-Z]{5}[0-9]{4}[A-Z]$")
    return candidate
```

async def create_tenant(
    session: AsyncSession,
    data: TenantCreate,
    *,
    kyb_company_data: dict[str, Any] | None = None,
) -> Tenant:
    """Create a tenant in the CREATED state and return it.

    When kyb_company_data is provided (the onboarding verify-then-create path),
    the tenant is born KYB-VERIFIED; otherwise kyb_status defaults to PENDING.
    """
    tenant = Tenant(
        company_name=data.company_name,
        primary_contact_name=data.primary_contact_name,
        primary_contact_email=data.primary_contact_email,
        business_type=data.business_type,
        website_url=str(data.website_url),
        pan=data.pan,
        timezone=data.timezone,
        language_preference=data.language_preference,
        status=TenantStatus.CREATED,
        onboarding_status=OnboardingStatus.PENDING,
    )
    if kyb_company_data is not None:
        tenant.kyb_status = KybStatus.VERIFIED
        tenant.kyb_company_data = kyb_company_data
        tenant.kyb_verified_at = datetime.now(UTC)
    session.add(tenant)
    await session.commit()
    await session.refresh(tenant)
    return tenant
```

```python
"""Thin async wrapper around Cashfree's PAN verification API (NSDL-backed).

Mock-first: when settings.pan_use_mock is True (the default) no network call is
made, so onboarding runs with no provider credentials. The live path follows
Cashfree's POST /verification/pan contract; tests/integration/test_pan_live.py
confirms it end-to-end once credentials exist.
"""

from typing import Any, TypedDict

import httpx

from core.config import get_settings
from core.exceptions import ExternalServiceError

# A valid-format PAN reserved by the mock to simulate "PAN not found".
_MOCK_NOT_FOUND_PAN = "AAAAA0000A"

# 4th character of a PAN encodes the holder type.
_CATEGORY_BY_TYPE_CHAR = {
    "P": "Individual",
    "C": "Company",
    "H": "HUF",
    "F": "Firm/LLP",
    "T": "Trust",
}


class PanData(TypedDict):
    """The subset of provider response we keep: registry name + holder category."""

    name: str
    category: str


async def verify_pan(pan: str) -> PanData | None:
    """Verify a PAN against the provider (or the mock). Return PanData if it
    exists, None if the provider reports it unknown/invalid. Raise
    ExternalServiceError on transient provider/network failure."""
    settings = get_settings()
    if settings.pan_use_mock:
        return _mock_verify(pan)
    return await _live_verify(
        pan, settings.pan_client_id, settings.pan_client_secret, settings.pan_base_url
    )


def _mock_verify(pan: str) -> PanData | None:
    if pan == _MOCK_NOT_FOUND_PAN:
        return None
    category = _CATEGORY_BY_TYPE_CHAR.get(pan[3], "Other")
    return PanData(name="Mock Verified Entity", category=category)


async def _live_verify(
    pan: str, client_id: str, client_secret: str, base_url: str
) -> PanData | None:
    headers = {
        "x-client-id": client_id,
        "x-client-secret": client_secret,
        "x-api-version": "2022-10-26",
        "Content-Type": "application/json",
    }
    try:
        async with httpx.AsyncClient(timeout=10.0) as http:
            response = await http.post(
                f"{base_url}/verification/pan", headers=headers, json={"pan": pan}
            )
    except Exception as exc:  # network/timeout — transient
        raise ExternalServiceError(f"PAN verify request failed: {exc}") from exc

    # For Cashfree a non-200 is OUR problem (bad config, auth, IP allowlist,
    # insufficient balance, rate-limit, provider down) — never "PAN invalid".
    if response.status_code != 200:
        raise ExternalServiceError(f"PAN provider returned {response.status_code}")

    data: dict[str, Any] = response.json()
    # A non-existent / deactivated PAN comes back as 200 with valid:false.
    if not data.get("valid") or data.get("pan_status") != "VALID":
        return None
    return PanData(name=data["registered_name"], category=data["type"])
```

"""KYB surface for tenant onboarding: verify a PAN via the PAN client.

```python
"""The /onboarding endpoint — verify PAN (KYB), create the tenant, start pipeline."""

from typing import Annotated

from arq.connections import ArqRedis
from fastapi import APIRouter, Depends
from sqlalchemy.ext.asyncio import AsyncSession

from auth.dependencies import get_current_user
from auth.models import User
from auth.service import set_user_tenant
from core.db import get_session
from core.exceptions import ConflictError, UnprocessableError
from core.queue import get_arq_pool
from modules.tenant_onboarding.kyb import verify_pan_kyb
from shared.tenant.schemas import TenantCreate, TenantRead
from shared.tenant.service import create_tenant

router = APIRouter()


@router.post("/onboarding", response_model=TenantRead)
async def onboard(
    data: TenantCreate,
    user: Annotated[User, Depends(get_current_user)],
    session: Annotated[AsyncSession, Depends(get_session)],
    arq_pool: Annotated[ArqRedis, Depends(get_arq_pool)],
) -> TenantRead:
    """Verify the PAN, then (only on success) create the tenant and start the pipeline."""
    if user.tenant_id is not None:
        raise ConflictError("User is already onboarded to a tenant")

    # Verify-then-create: a failed PAN creates nothing, so there are no orphan rows.
    company_data = await verify_pan_kyb(data.pan)
    if company_data is None:
        raise UnprocessableError("PAN could not be verified")

    tenant = await create_tenant(session, data, kyb_company_data=company_data)
    await set_user_tenant(session, user, tenant.id)
    # If enqueue fails here the tenant is VERIFIED but the pipeline never starts;
    # that needs admin reconciliation (a deferred follow-up).
    await arq_pool.enqueue_job("run_onboarding_pipeline", tenant_id=str(tenant.id))
    return TenantRead.model_validate(tenant)
```
